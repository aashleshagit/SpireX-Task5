# Responsive Customer Testimonials Section

## 📌 About the Project

This project is a responsive and interactive Customer Testimonials Section developed using HTML, CSS, and JavaScript.

It displays customer feedback in an attractive card-based layout with customer profile images, ratings, names, and designations.

## 🚀 Features

- Responsive design for desktop and mobile devices.
- Attractive testimonial card layout.
- Customer profile images.
- Five-star customer ratings.
- Interactive Previous and Next buttons.
- Smooth hover effects.
- Dynamic content updates using JavaScript.

## 🛠️ Technologies Used

- HTML5 – Structure of the webpage.
- CSS3 – Styling and responsive design.
- JavaScript – Interactive testimonial navigation.

## 💻 How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.
